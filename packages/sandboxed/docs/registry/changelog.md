# Changelog

## 0.1.3 — screenshot gallery

- Added real screenshots of the sandboxed builder and submissions inbox.
- Demonstration submissions use synthetic data; no runtime or permission changes.

## 0.1.2 — registry artwork

- Added the EmQuix Forms family icon and a wide featured banner.
- Branding only: form behavior, permissions and host compatibility are unchanged.

## 0.1.1 — registry renderer connection

- Embed instructions use EmDash's actual installed plugin ID.
- Renderer 0.1.1 accepts that ID for both definition and submission requests.
- Verified the generated-ID journey after a fresh signed registry installation.

## 0.1.0 — first sandboxed release

- Sandboxed form storage, native Block Kit builder and submission inbox.
- Shared templates, 15 field types and nested conditional logic.
- Revision-checked edits, draft duplication, publication and revision restoration.
- Conditional notifications with customizable plain-text message bodies.
- Optional Turnstile, bounded requests, rate limits and payload-bound retries.
- Entry notes, moderation, revision-checked erasure and CSV/JSON exports.
- Separate free Astro renderer and Advanced editor in the public source repository.
- Runtime reduced below EmDash's publishing file-size limit using the lightweight validation build.

See the repository's release report for executed test evidence and deployment limitations.
